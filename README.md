Trouve ton artisan
Site de la région Auvergne Rhône-Alpes
Objectif : Trouver un artisan et le contacter

Prérequis :
- Node.js
- MySQL

Technologies utilisées :
- Express
- Bootstrap
- Sass
- ReactJS

Base de données :
- database/creation.sql
- database/alimentation.sql

API :
- cd backend
- npm install

Site :
- cd frontend
- npm install

Copier .env.example en .env et le remplir

Dans un terminal et un second :
- cd backend puis npm run dev
- cd frontend puis npm run dev

Site accessible sur http://localhost:5173
